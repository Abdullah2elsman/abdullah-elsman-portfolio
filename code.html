Share-k: Developer Collaboration Platform

ITI Graduation Project Backend Developer Team of 6

System Concept

Share-k is a platform designed to bridge the gap between project owners and contributors. The core mechanism relies on an AI-assisted skill evaluation engine that analyzes contributor profiles and matches them with appropriate technical requirements set by project creators. This ensures a high-fidelity alignment of technical capabilities with project demands.

Challenges & Decisions

Async Job Processing

The AI evaluation process was resource-intensive. Implementing Redis-backed job queues allowed us to decouple the evaluation process from the main request thread, preventing timeouts and ensuring system stability under load.

Team Collaboration

Coordinating across a team of 6 required strict API contracts and robust CI/CD pipelines. We enforced rigorous code reviews and utilized Swagger for automated documentation to maintain alignment between frontend, backend, and AI service teams.
